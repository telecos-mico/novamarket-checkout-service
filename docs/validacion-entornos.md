# Validación de entornos

## Entorno local
Permite validar de forma básica el funcionamiento del sistema.

## Entorno de pruebas
Simula condiciones más cercanas a producción.

## Criterio para considerar la guía lista
Todo el flujo debe ejecutarse correctamente sin errores.

## Riesgo de validar solo una parte del proceso
Podrían existir fallos no detectados en producción.
